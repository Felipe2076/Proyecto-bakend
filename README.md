# SIGED La Serena — Proyecto Backend

Sistema Integrado de Gestión de Requerimientos Municipales y Matriz SGR.

Repositorio de entrega: [Felipe2076/Proyecto-bakend](https://github.com/Felipe2076/Proyecto-bakend)

## Cómo ejecutar

```powershell
git clone https://github.com/Felipe2076/Proyecto-bakend.git
cd Proyecto-bakend
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py runserver
```

Abrir http://127.0.0.1:8000/
